# 泳堂管家

一個為游泳教練而設、手機優先的本機課堂管理 Web App。

## 功能

- 日、週、月時間表及編排課堂
- 課程、級別、課室及預約設定
- 學生與導師資料管理
- 完成、改期或取消課堂
- 預繳堂數、續費提醒、收款、收據及月結
- 數位手冊：功課、筆記及相片
- 家長／導師帳戶目錄
- 課程產品、公告欄、聯絡及說明中心
- 深色模式及 JSON 備份／還原

## 資料私隱

目前版本的資料只儲存在使用者的瀏覽器，不會自動同步到雲端。請勿輸入身份證號碼、健康紀錄、密碼或其他敏感資料，並定期匯出備份。
